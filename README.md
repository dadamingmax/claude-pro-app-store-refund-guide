# Claude Pro 被封了怎么退款？苹果 App Store 退款申请教程（附英文申诉模板）

最近 Claude 护照认证完秒封，很多人都中招了。



![img](https://pic1.zhimg.com/v2-e246a0e860b5a387e27a02265e8809a6_1440w.jpg)



实测走 App Store 订阅的，被封后可以直接找苹果退款，流程很简单，比起坐以待毙，直接主动出击。

### **退款步骤：**

1. 打开苹果退款官网：[https://reportaproblem.apple.com](https://reportaproblem.apple.com/)
2. 选择 **Request a refund**



![img](https://pic1.zhimg.com/v2-0df6e7f9bebf4d7214a9daf5febb792a_1440w.jpg)



1. 退款原因选 **Other**



![img](https://pica.zhimg.com/v2-ba97a431be3c54757749dbfabb665704_1440w.jpg)



1. 勾选对应的 Claude 订阅



![img](https://pic2.zhimg.com/v2-f38eea4e564ee0a64b4b93a548b965a1_1440w.jpg)





1. 填理由提交（24-48 小时出结果）





![img](https://picx.zhimg.com/v2-7ae935fdf54e3add7214a45ac2d66f95_1440w.jpg)



### **退款理由模板（直接复制）：**

I’m requesting a refund for my Claude Pro subscription. Shortly after I upgraded to Pro and completed the payment, my account triggered a KYC verification requirement. After the verification process, my account was restricted/disabled and I can no longer access the paid Pro features or use the service I paid for.Since the paid subscription is now inaccessible due to this sudden KYC lock, I kindly request a full refund.Thank you.

### **中文翻译：**

我申请退还 Claude Pro 订阅费用。

在我升级至 Pro 并完成付款后不久，我的账号便触发了 KYC 身份验证要求。完成验证流程后，我的账号被限制或封禁，导致我无法继续访问 Pro 会员功能，也无法正常使用已经付费购买的服务。

由于突发的 KYC 验证及账号限制问题，我已无法使用所购买的付费订阅服务。因此，我恳请苹果退还此次订阅费用。

感谢您的理解与帮助。
